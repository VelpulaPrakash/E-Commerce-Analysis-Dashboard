Developed an interactive sales analysis dashboard using Microsoft Excel to analyze order trends, customer purchasing behavior, product popularity, shipping duration, and customer satisfaction. The dashboard provides an at-a-glance view of key business metrics and enables users to explore data through interactive slicers.
# 📊 Excel Sales Analysis Dashboard

## 📌 Project Overview
This project presents an interactive Sales Analysis Dashboard built using Microsoft Excel. It transforms raw order data into meaningful business insights through KPIs, PivotTables, PivotCharts, and interactive slicers.

The dashboard helps analyze sales performance, order trends, customer purchasing behavior, product popularity, shipping duration, and customer satisfaction.

## 🎯 Project Objectives
- Analyze overall order and sales performance.
- Identify popular products and customer purchasing patterns.
- Track order trends over the last 13 weeks.
- Analyze orders across different genders and sales channels.
- Evaluate shipping duration and customer satisfaction.
- Build an interactive dashboard to support data-driven decisions.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- PivotTables and PivotCharts
- Excel Slicers
- KPI Cards
- Data Analysis and Visualization

## 📈 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)
The dashboard displays the following metrics:
- Total Orders
- Total Quantity
- Total Amount
- Average Customer Rating
- Average Shipping Days

### 2. Order Trend Analysis
Visualizes order trends over the last 13 weeks to help understand changes in order activity over time.

### 3. Gender and Sales Channel Analysis
Analyzes order distribution across gender categories and sales channels, including App, Instagram, Partner App, Target.com, and Website.

### 4. Customer Purchasing Behavior
Examines purchasing patterns using group-based comparisons to understand customer buying behavior.

### 5. Product Popularity Analysis
Identifies popular products based on order volume and compares demand across different product categories.

### 6. Shipping Duration Analysis
Analyzes the number of days taken to ship orders to understand shipping performance.

### 7. Customer Satisfaction Analysis
Visualizes customer ratings to evaluate satisfaction levels and identify opportunities for improvement.

### 8. Interactive Dashboard Filters
Uses Excel slicers to filter dashboard data by:
- Gender
- Order Channel

These filters allow users to explore different customer segments and sales channels interactively.

## 💡 Business Value
This dashboard can help businesses:
- Monitor key sales and order metrics.
- Identify products with higher demand.
- Understand customer purchasing patterns.
- Track shipping performance.
- Evaluate customer satisfaction.
- Make informed business decisions using data visualization.

## 🚀 Conclusion
This project demonstrates the use of Microsoft Excel for exploratory sales analysis and interactive dashboard development. It showcases practical data analytics skills by converting order data into an accessible visual report for monitoring business performance and customer behavior.
